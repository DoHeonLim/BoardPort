# 보드게임 도감 데이터/화면 설계

BoardPort의 보드게임 도감은 상품, 게시글, 방송이 함께 참조하는 기준 데이터 역할을 합니다.

목표는 외부 설명을 대량 수집하는 것이 아니라, 보드게임을 식별하고 BoardPort 안의 콘텐츠를 연결할 수 있는 구조화 메타데이터를 만드는 것입니다.

## 1. 설계 목적

- 상품 등록 시 어떤 보드게임인지 명확히 연결
- 게시글과 방송도 같은 보드게임 기준 정보와 연결
- 도감 상세에서 관련 상품, 게시글, 방송을 역탐색
- 한국어 제목, 별칭, 짧은 설명은 관리자 검수 후 공개

## 2. 데이터 원칙

사용 가능한 데이터:

- Kaggle CSV 기반 BGG 구조화 메타데이터
- 관리자가 입력하거나 검수한 한국어명, 별칭, 요약
- 발매연도, 인원, 시간, 난이도, 카테고리, 메커니즘 같은 사실 정보

사용하지 않는 데이터:

- 쇼핑몰 상품 상세 설명
- 퍼블리셔 공식 소개문
- 룰북 본문
- 블로그, 커뮤니티 후기 문장
- BGG 장문 description 원문 또는 번역본

AI 생성 결과는 한국어 초안 작성 보조 용도로만 사용하며, 공개 전 관리자 검수와 수동 편집을 거칩니다. 최종 공개 여부는 `BoardGameLocale`의 검수 상태를 기준으로 결정합니다.

## 3. 데이터 모델

핵심 모델은 다음 역할로 나눕니다.

- `BoardGame`: BGG ID, 원제, 이미지, 인원, 시간, 난이도 같은 원천 메타
- `BoardGameLocale`: 한국어 제목, 별칭, 짧은 설명, 검색 키워드, 공개 상태
- `BoardGameTaxonomy`: 카테고리/메커니즘 분류
- 연결 테이블: 상품, 게시글, 방송과 보드게임 연결

공개 도감은 `PUBLISHED` 상태의 한국어 locale을 기준으로 노출합니다.

## 4. Import 흐름

1. Kaggle CSV 기반 원천 데이터를 관리자가 준비
2. 원천 보드게임 메타데이터 import
3. 한국어 검수 CSV import
4. 메커니즘/카테고리 relation import
5. taxonomy 한국어명 import
6. 검수 완료 항목만 공개

CSV 원본 파일은 저장소에 포함하지 않고, 운영자가 별도로 관리합니다.

## 5. 화면 구성

### `/boardgames`

- 검색어
- 인원, 시간, 난이도 필터
- 정렬
- 명시적 페이지 이동
- 도감 카드 목록

### `/boardgames/[id]`

- 기본 메타데이터
- 한국어 요약
- 카테고리/메커니즘
- 관련 상품, 게시글, 방송
- 비슷한 게임 추천

### 작성/수정 폼

상품, 게시글, 방송 작성 시 연결 보드게임을 선택할 수 있습니다.

## 6. 주요 판단

- 하단 TabBar에는 도감 탭을 추가하지 않고, 상품 탐색의 보조 진입점과 독립 라우트로 제공
- 도감은 무한 스크롤보다 페이지 이동이 적합하다고 판단
- 장문 설명 저장보다 구조화 메타데이터와 관리자 검수 데이터를 우선
- 추천, 사용자 제보, 룰북 기반 Q&A는 후속 확장으로 분리

## 7. 주요 설계 포인트

- 외부 데이터 사용 범위와 저작권 리스크를 명시적으로 제한
- 원천 데이터와 한국어 공개 데이터를 분리
- 도감이 독립 기능이 아니라 상품/게시글/방송과 연결되는 기준 데이터로 작동
- 관리자 검수와 공개 상태를 통해 데이터 품질 관리
